# Mission 2, slice 1 (map) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Load cna's map (`vendor/cna/data/map/`) into typed Rust: hexes,

## Domain facts the implementer needs

- **Hex ids** match `^[A-EM][0-9]{4}$`: sheet letter, then row (RR) and
  column (CC), e.g. `C3922` is sheet C, row 39, column 22. Rows increase
  northward, columns eastward. 7073 hexes; `hexes.json` rows are
  `{id, sheet, terrain, settlement, coastal}`.
- **Adjacency** (cna `tools/map_geom.py`, `data/README.md` "Hex grid
  convention"): every sheet in `sheets.json` has `odd_rows_shift`. A row
  is shifted east when `(row odd) == (odd_rows_shift == "east")`. The six
  neighbours of `(r, c)` are `(r, c±1)` and `(r±1, lo)`, `(r±1, hi)` with
  `(lo, hi) = (c, c+1)` for an east-shifted row, else `(c−1, c)`. Drop any
  that is not in `hexes.json`. Checked values: `C3922` →
  `C3821 C3822 C3921 C3923 C4021 C4022`; `E1730` →
  `E1629 E1630 E1729 E1731 E1829 E1830`.
- **Cross-sheet adjacency** is not in cna yet (sheets "join along printed
  hex numbers"); requested under **Requests for cna**. This slice gives
  same-sheet adjacency and an `#[ignore]`d test naming a C–D pair once cna
  lands the join.
- **Hexsides** (`hexsides.json`): only hexsides with features are listed,
  keyed `"<a>|<b>"` with `a < b`. `features` from: escarpment, ridge, slope,
  wadi, major-river, minor-river, road, unfinished-road, railroad,
  unfinished-railroad, track, coast, lake. `up` names the higher hex for a
  slope or escarpment. Edge records have `b: null` and `side` (E, SE, SW,
  W, NW, NE); keep them, keyed `"<a>|<side>"`. Example: `C3921|C3922` is an
  escarpment, up `C3921`.
- **Places** (`places.json`): `{id, hex, name, kind, port}`; 51 places.
  Alexandria is two places (`alexandria-east`, `alexandria-west`).
- **Regions** (`regions.json`): sheets A, B are Libya, D, E Egypt; sheet C
  is split: a hex on row `r` is in Egypt when its column is
  `>= first_east_col[r]`.
- Map corrections (`data/map/corrections/`) are already applied to
  `hexes.json` and `hexsides.json`; do not apply them again.
