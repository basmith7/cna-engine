# Mission 3, slice 3 (map and counters) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A browser page that shows the whole theatre in cna's map style,
every Graziani unit as a counter, and the clock, with pan and zoom.

**Architecture:** `web/` is a Vite + Svelte 5 + TypeScript app
(`npm create vite@latest web -- --template svelte-ts`, then trimmed).
`npm run wasm` runs `wasm-pack build ../crates/cna-web --target web
--out-dir ../../web/src/pkg`; `src/pkg` is git-ignored. `src/engine.ts`
wraps the `Game` class in typed functions; `src/types.ts` holds TS types
for `View`, `Order`, `Event`, `Reach` (hand-written now; switch to
`ts-rs`/`tsify` generation later if they drift, noted in the spec).

**Spec:** `docs/designs/2026-10-13-minimal-ui-design.md`
**Previous plans:** slices 1–2.

## Domain facts the implementer needs

- **Style source:** `vendor/cna/tools/map_render.py` `PALETTE`,
  `STROKES` and `_style()`: copy these into `src/map.css` as the same
  class names (`.terrain-desert`, `.hexside.escarpment`, …) with a comment
  pointing at the file and the cna commit. Settlements: major city a
  square, village/bir/oasis a dot; labels as there.
- **No SPI art.** Do not add any image file to `web/`. Counters are SVG
  drawn from `view()` data.
- **Counters:** a 0.8-hex square; band colour by nation (a table in
  `src/counters.ts`, distinct for Italian, Libyan, British, Indian,
  Australian, New Zealand, Free French, …; Axis warm, Commonwealth cool);
  a NATO frame with branch glyph from `unit_type` (infantry cross,
  armour ellipse, artillery dot, HQ flag, motorised wheels, recon slash,
  engineer E, supply/truck as the fallback "other"); size marks from
  `equivalent` (II battalion, X brigade, XX division, I company); text:
  `id_code` top, TOE and CPA bottom.

## Tasks

1. **Scaffold.** Vite app, ESLint and Prettier defaults from the
   template, `npm run check` (svelte-check), Vitest, Playwright
   (`npm init playwright`, Chromium only). `.gitignore` for `node_modules`,
   `src/pkg`, `test-results`. Commit `web: scaffold`.
2. **Engine wrapper and store.** `engine.ts` (init wasm, `newGame`,
   `view`, …), a Svelte store `game` holding `Game` and `View`,
   refreshed after every call. Vitest: with wasm initialised from the
   file in Node, a new game's view has the scenario's piece count.
   Commit `web: engine store`.
3. **Map.** `Map.svelte`: hex polygons with `data-hex`, hexside paths,
   settlements, labels, from `geometry()` once; pan (drag), zoom (wheel,
   about the cursor), fit to sheets B–E on start, "go to hex" input. Keep
   labels and hex numbers hidden below a zoom threshold. Vitest:
   viewBox maths. Commit `web: theatre map`.
4. **Counters and stacks.** `Counter.svelte` and `Stack.svelte` on a layer
   above the map, `data-unit` per counter; stack badge; click a hex to open
   the stack panel (read-only this slice). Off-map boxes (Tripoli, Cairo
   …) as a strip of labelled boxes beside the map holding their counters;
   pending set-up pieces in a "to place" tray per side. Vitest: every
   `unit_type` in Graziani maps to a glyph (no fallback for combat units).
   Commit `web: counters`.
5. **Top bar.** Clock, weather, initiative, Player A, acting player.
   Commit `web: status bar`.
6. **Smoke e2e.** Playwright: `npm run build && npm run preview` as the
   web server; page loads, at least 7 000 `[data-hex]`, every placed
   piece has a `[data-unit]`, the top bar says Game-Turn 1 set-up; save a
   screenshot artefact (not compared). Stop the preview server in
   teardown (Playwright's `webServer` does). Commit `web: smoke test`.
7. **CI job `web`:** Node 22, wasm-pack, `npm ci`, `npm run wasm`,
   `npm run check`, `npm test`, `npx playwright install --with-deps
   chromium`, `npx playwright test`.
