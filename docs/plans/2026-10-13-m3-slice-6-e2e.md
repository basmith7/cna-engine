> **For agentic workers:** implement this plan task by task with the
> **implement-spec** skill. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Loading a save cannot crash the page; save, load and
autosave; M2's golden game played through the UI in CI; Mission 3's
docs.

**Spec:** `docs/designs/2026-10-13-minimal-ui-design.md`

## Rules for every task

- Stage only your own files (`git add <paths>`, never `git add -A`).
- Paste the output of each verification command into the PR body; do not
  summarise it as "passes".
- Stop any dev or preview server you start (`npm run dev`, `npm run
  preview`) before finishing; Playwright's `webServer` stops its own.
- On any visual change, capture the slice's proving screenshots with
  Playwright at 1440×900 (plus one at 390×844) into
  `~/Projects/cna-m3-shots/slice-N/` under the names below, run the
  **screenshot-critique** skill on them, fix what it finds, and paste its
  verdict in the PR.
- `export CARGO_TARGET_DIR=$HOME/.cache/cna-engine-target`; a gate that
  fails on data this tree does not have is re-run before being believed
  (spec, *Risks*).

## Tasks

1. **`from_json` checks invariants.** Before Load is offered:
   `GameState::from_json` refuses, with an error and no panic, a `sealed`
   pending with an empty `waiting` (today a panic in `Pending::side`), a
   clock outside its invariants (stage 1–3, `half` only in phases F–L,
   `segment` only in G), and a pending whose side or pieces do not exist.
   One test per malformed save, and `wasm-pack test` loading one of them
   returns the error string. Commit `from_json: refuse malformed saves`.
2. **Save.** Button downloads `graziani-gt<N>-os<M>.json` (`save()`).
   Commit `web: save`.
3. **Load.** File input; a `load` error (wrong `rules_commit`,
   malformed) is shown and the current game kept. Commit `web: load`.
4. **Autosave.** `save()` to `localStorage` after each accepted order;
   on start, "Continue" if present, else "New game" with a seed field
   (random default, shown). Commit `web: autosave`.
5. **The golden game.** "New game" with seed 7, then a driver maps each
   `LoggedOrder` of `graziani-short.json` to the clicks that produce it
   (tray + hex, stack + reachable hex, panel inputs, buttons; the slice
   3–5 helpers for orders 0–76) and asserts after each that the DOM's
   counters match `__cna.view()` (sampled after order 87 if the run is
   too slow: spec, *Risks*). After order 87 (the scripted fighting
   done): save, reload the page, load the file, continue. End: the end
   dialog open with no level for either side, and `__cna.save()`
   byte-equal to `cna-play replay` of the same log. An order the driver
   cannot express by clicks is a failing test, not a skipped one.
   Capture the proving screenshots, run screenshot-critique, fix what it
   finds. Commit `web: e2e golden game`.
6. **Docs.** README: running the UI (`cd web && npm ci && npm run wasm &&
   npm run dev`, toolchain), nothing hosted, the secrecy limits;
   `NOT_SIMULATED.md`: the UI enforces nothing itself; the design's
   Status; `AUTOPILOT.md` queue; `MISSION 3 COMPLETE` in the journal and
   `PROGRESS.md`.
