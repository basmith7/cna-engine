# Mission 4, slice 6 (ship) Implementation Plan

> **For agentic workers:** implement this plan task by task with the
> **implement-spec** skill. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One image, built and published by a tag, that Brian can run on
Tower with compose and Postgres; his checklist exact; the mission's docs
done. Nothing is deployed by the autopilot.

**Spec:** `docs/designs/2026-10-13-multiplayer-server-design.md`
(*Image*, *Brian's checklist*)
**Depends on:** slice 5 merged.

## Rules for every task

- As slice 5. Never push a tag, never run `scripts/deploy-now.sh`,
  never touch Tower, Pangolin, Cloudflare or Discord's real API.
- Docker must already be on the machine; if it is not, write the files,
  skip the local build, and say in the PR that the image is unverified.

## Tasks

### Task 1: the image

- [ ] `Dockerfile` per the spec's *Image* row, with a `.dockerignore`
  (`target/`, `web/node_modules`, `web/src/pkg`, `.git`): the commit
  comes in as the build arg `CNA_RULES_COMMIT` (`git -C vendor/cna
  rev-parse HEAD` in the workflow and `smoke.sh`), which `cna-embed`'s
  `build.rs` prefers since slice 1. Built without `test-auth` and
  `fake`.
- [ ] `docker build -t cna:dev .` locally; paste the size. Commit.

### Task 2: production compose and a smoke test

- [ ] `deploy/compose.prod.yml`: `cna-db` (postgres:18, data on a bind
  mount `${CNA_DATA:-/mnt/cache/appdata/cna}/pg`) and `cna` (the image,
  host port 3240, `env_file: .env`, `depends_on` healthy db, the
  `net.unraid.docker.icon` and `.webui` labels as Brian's other apps).
  `deploy/.env.example` with every `CNA_*` name and no values.
- [ ] `scripts/smoke.sh`: brings up `compose.prod.yml` with the local
  image, a temp data dir and the fake Discord (an override file),
  waits for `/healthz`, signs in as `alice` with `curl`, creates a game,
  tears everything down. Run it; paste the output. Commit.

### Task 3: publish and deploy scripts

- [ ] `.github/workflows/docker-publish.yml`: on `v*` tags, run the
  gates, then build and push `ghcr.io/basmith7/cna:<tag>` and `:latest`
  with `docker/build-push-action` and `GITHUB_TOKEN` (`packages: write`).
- [ ] `scripts/deploy-now.sh`, modelled on Brian's other apps'
  (`Infrastructure.md`, *Deploying an app*): wait for the tag's
  publish run, then `ssh tower bash /boot/config/bin/deploy-app cna`.
  Written, not run. Commit.
