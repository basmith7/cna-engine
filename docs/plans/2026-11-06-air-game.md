# Mission 7: the Air Game, Implementation Plan

> **For agentic workers:** implement this plan task by task with the
> **implement-spec** skill. Steps use checkbox (`- [ ]`) syntax for tracking.

**Spec:** `docs/designs/2026-11-06-air-game-design.md`. Where this plan and
the spec disagree, follow the spec and say so in the journal.
**Depends on:** Brian's approval of the spec in **Feedback** (Mission 7 is
under his review), and cna's answers to the spec's Requests 1, 3, 4 and 5 for
tasks 1, 4, 5 and 6. Nothing below is built until then.

Every decision here is the autopilot's under Brian's delegation of
2026-09-26 and is reversible with one PR.

Slice 1 has its full task list here. Slices 2–8 have a task list each;
each gets its own plan (`docs/plans/YYYY-MM-DD-m7-slice-n-<slug>.md`) at its
start, written against the code the slices before it leave behind.

## Rules for every task

- Stage only your own files (`git add <paths>`, never `git add -A`).
- Paste each verification command's output into the PR body.
- `CARGO_TARGET_DIR` on disk under `work/targets/`, not `/tmp` (tmpfs).
- Failing test first, every task; cite the case in each test name or
  comment, never the rule text.
- The old goldens (`tests/games/*.json`) and every fixture in
  `web/tests/fixtures/` must replay to their pinned hashes with no
  regeneration. A slice that changes one has leaked into games without the
  module: fix the slice, do not re-pin.
- Gates for `gh pr ready`: `cargo clippy --all-targets -- -D warnings`,
  `cargo test --no-fail-fast`, `cargo run -p cna-probe -- check`, the `web/`
  checks and Playwright.

## Slice 1: the switch, set-up and maintenance (Graziani's Offensive)

**Goal:** `cna-play new --air` starts Graziani's Offensive with every
aircraft of `sides.*.air` in squadrons at air facilities, pilots by rating,
SGSUs placed, Malta's aircraft, AA points and capacity set. In each
Operations Stage the SGSUs refuel, refit and arm within facility capacity
at §47.2's costs, and aircraft may transfer between facilities. The browser
shows facilities and squadrons and can play such a game. No other mission
flies yet; the abstract air rules the module replaces are off from
this slice, their replacements logged as still to come.
