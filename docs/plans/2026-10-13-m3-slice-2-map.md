# Mission 3, slice 2 (map and counters) Implementation Plan

> **For agentic workers:** implement this plan task by task with the
> **implement-spec** skill. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The theatre in cna's map style with every Graziani piece as a
counter, off-map boxes and the set-up tray, pan and zoom, within the
performance budget.

**Spec:** `docs/designs/2026-10-13-minimal-ui-design.md`
**Previous plans:** slice 1.

**Proving screenshots:** `slice-2/start.png`, the start position fitted
to sheets B–E; `slice-2/sidi-barrani.png`, zoomed on Sidi Barrani with a
stack badge and an open stack panel.

## Rules for every task

- Stage only your own files (`git add <paths>`, never `git add -A`).
- Paste the output of each verification command into the PR body; do not
  summarise it as "passes".
- Stop any dev or preview server you start (`npm run dev`, `npm run
  preview`) before finishing; Playwright's `webServer` stops its own.
- On any visual change, capture the slice's proving screenshots with
  Playwright at 1440×900 (plus one at 390×844) into
  `~/Projects/cna-m3-shots/slice-N/` under the names below, run the
  **screenshot-critique** skill on them, fix what it finds, and paste its
  verdict in the PR.
- `export CARGO_TARGET_DIR=$HOME/.cache/cna-engine-target`; a gate that
  fails on data this tree does not have is re-run before being believed
  (spec, *Risks*).

## Domain facts

- **Style source:** `vendor/cna/tools/map_render.py` `PALETTE`,
  `STROKES`, `_style()`: copy into `src/map.css` with the same class
  names and a comment naming the file and cna commit. Settlements from
  `places.json`: a `Place` may cover several hexes (`hexes`, PR #10);
  draw the marker on `hex`, shade all of `hexes`.
- **No SPI art.** No image files in `web/`.
- **Counters:** 0.8-hex square; band by `nation` (Axis warm, Commonwealth
  cool); NATO frame with glyph from `unit_type` (infantry, armour,
  artillery, HQ, motorised, recce, engineer, fallback "other"); `kind`
  `supply-unit` / `dummy-supply-unit` get a supply glyph (dummies look
  identical to real ones to both players: no hidden info, but don't
  advertise it); size mark from `equivalent`; `id_code` top, TOE and CPA
  bottom. Small markers from the view: `reserve` (I/II), `contact` /
  `engaged`, and in a combat segment `combat.pinned` and
  `combat.forward`.

## Tasks

1. **Styled base layer.** Terrain classes, hexsides, settlements, labels;
   still rendered once, outside reactive state; one delegated click
   handler. Labels and hex numbers hidden below a zoom threshold. Commit
   `web: cna map style`.
2. **Pan, zoom, go to hex.** `viewBox` maths in a pure module with
   Vitest. Commit `web: pan and zoom`.
3. **Counters and stacks.** A counters layer keyed by hex, rebuilt from
   `view` only; `data-unit` per counter; stack badge; stack panel
   (read-only). Off-map strip by `OffMapBox`, transit list, "to place"
   tray per side. Vitest: every `unit_type` in Graziani maps to a glyph
   (no fallback for combat units). Commit `web: counters`.
4. **Performance budget.** Playwright measures time to first counters
   and one wheel-zoom step (`performance.now()` around it); assert under
   3 s and 100 ms; record numbers in the PR. If missed, apply the spec's
   fallbacks in order and say which. Commit `web: performance check`.
5. **e2e.** Every placed piece has a `[data-unit]` at its hex; every
   pending piece is in the tray; the 59 pending pieces of a new game
   (36 Axis, 23 Commonwealth) are all in the trays. Capture the two
   proving screenshots, run screenshot-critique, fix what it finds.
   Commit `web: e2e map`.
